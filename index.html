Sobre o projeto

A Biblioteca Digital Acessível é um projeto educativo que organiza materiais de leitura e estudo em uma página simples, intuitiva e adaptável a diferentes dispositivos.

O projeto utiliza HTML semântico, CSS responsivo, textos objetivos, imagens com descrição e links com nomes claros para facilitar a navegação.
