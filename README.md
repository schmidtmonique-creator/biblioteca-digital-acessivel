
# 📚 Biblioteca Digital Acessível

## Sobre o projeto

A Biblioteca Digital Acessível é um projeto educativo desenvolvido
com HTML5 e CSS3 para organizar materiais de leitura e estudo de
maneira simples, clara e acessível.

O objetivo é facilitar a navegação e incentivar o acesso ao conhecimento.

## Funcionalidades

- Página inicial com apresentação do projeto.
- Menu de navegação por seções.
- Seis cards de livros fictícios e educativos.
- Categorias organizadas por área de conhecimento.
- Links para consultar os detalhes dos materiais.
- Seção sobre o projeto.
- Layout responsivo para computadores, tablets e celulares.

## Categorias disponíveis

- 💻 Tecnologia
- 📖 Literatura
- 🔬 Ciências
- ➗ Matemática
- 🏛️ História
- 🌱 Desenvolvimento pessoal

## Acessibilidade

O projeto utiliza boas práticas de acessibilidade:

- HTML semântico com cabeçalhos hierárquicos.
- Textos objetivos e fonte legível.
- Contraste entre texto e fundo.
- Imagens com descrições no atributo `alt`.
- Links com nomes claros.
- Navegação por teclado com destaque de foco.
- Link para pular diretamente ao conteúdo principal.
- Espaçamento adequado entre os elementos.
- Layout responsivo para diferentes telas.
- Respeito à preferência por movimento reduzido.

## Tecnologias utilizadas

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media queries

## Estrutura dos arquivos

```text
biblioteca-digital-acessivel/
├── index.html

└── README.md
```

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Navegue pelas seções utilizando o menu.
